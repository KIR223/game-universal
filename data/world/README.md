# data/world — набор данных реального мира (контракт для всех платформ)

Собирается `tools/world/build_world.py`; описание источников — `docs/DATA_SOURCES.md`. Любое изменение набора = новый `world_hash`.
Файлы — zlib (формат совместим с `PackedByteArray.decompress_dynamic(-1, FileAccess.COMPRESSION_DEFLATE)`), числа — little-endian.

| Файл | Содержимое |
|------|------------|
| `manifest.json` | версия, дата сборки, параметры растра, счётчики, sha256 каждого файла, `world_hash` |
| `raster_cells.bin` | int32[W×H]: id ячейки на пиксель (−1 — вода вне морских зон / озёра). Равнопромежуточная проекция, 0.2°/пиксель, широты 84°…−60° |
| `raster_region.bin` | int32[W×H]: id региона (1-based; 0 — вода) |
| `raster_elev.bin` | int32[W×H]: высота/глубина, м |
| `raster_order.bin` | int32[…]: индексы пикселей, отсортированные по id ячейки (длины — `cells.pixels`) |
| `raster_ids.bin`, `raster_relief.bin` | текстуры для GPU: id ячеек (RG8) и подсвеченный рельеф (RGB8) |
| `adj.bin` | int32[N×3]: пары смежных ячеек (lo, hi, длина общей границы в пикселях), включая «склейку» через 180° |
| `links.bin` | int32[N×3]: (ячейка A, ячейка B, 1 — дорога / 2 — железная дорога) |
| `cells.json.z` | колонки по ячейкам: центр, площадь, регион, страна, местность, население, промышленность, инфраструктура, месторождения, спор |
| `countries.json.z` | страны (admin-0), суверены, спорные территории |
| `regions.json.z` | регионы: 1..n_country_regions — «страна как регион», далее admin-1 |
| `settlements.json.z` | колонки населённых пунктов; **id упорядочены по населению (убывание)** |
| `facilities.json.z`, `lines.json.z` | порты и аэропорты; дороги, железные дороги, реки, границы (упрощённые) |

## Правила идентификаторов

- ID ячеек — `0..N−1`: сначала суша (по возрастанию региона, затем порядок построения), затем море. Детерминированы.
- Регион ячейки не меняется; страна-владелец и контролёр — изменяемое состояние симуляции (`owner[]`, `legal[]`), геометрия неизменна.
- Ячейки вложены в административные регионы, но контроль над ячейками независим от границ регионов.
