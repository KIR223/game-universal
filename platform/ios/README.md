# IRON DOMINION на iPhone / iPad

Состояние: **игра собрана и запускается в iOS Simulator (iPhone 17, iOS 27.2, Xcode 27.2)**: главное меню, выбор страны, HD-карта с русскими названиями, HUD с нижней навигацией, снег по правилу погоды. Память ≈ 208 МБ (RSS процесса в симуляторе). На реальном iPhone игра ещё не запускалась (нужна подпись: Apple ID / Team ID).

### Важно: библиотека симулятора
В официальных export templates Godot 4.7.2 библиотека для симулятора (`ios-arm64_x86_64-simulator`) содержит **только x86_64**; симулятор iOS 27 такое приложение не запускает. Поэтому arm64-библиотеку для симулятора нужно собрать из исходников Godot один раз (≈ 15 минут на M1):
```bash
scons platform=ios arch=arm64 ios_simulator=yes target=template_debug vulkan=no -j6
```
и передать путь к `bin/libgodot.ios.template_debug.arm64.simulator.a` скрипту `platform/ios/build_simulator.sh` (экспорт → слияние библиотек → xcodebuild → установка и запуск). Для реального устройства (arm64) шаблоны подходят как есть.

## Что уже сделано в коде
- Сенсорное управление (`game/rendering/touch_gestures.gd`): одним пальцем — сдвиг и выбор, двумя — масштаб и сдвиг, долгое нажатие (0,5 с) — «правый клик» (приказ/контекст). Логика покрыта тестами на синтетических событиях.
- Безопасные зоны (`game/ui/mobile_layout.gd`): интерфейс не заходит под вырез, скруглённые углы и индикатор «Домой».
- Масштаб интерфейса ×1,3 на телефонах; навигация — нижняя панель вместо левой рейки; панель «Журнал» скрыта и открывается кнопкой; панели не выходят за окно (тест `-- --phone`).
- Сценарии, чьи карты не вошли в сборку, не показываются (для телефона исключена XL-карта).
- Проверка раскладки на ПК: `godot --path . -- --phone-ui` (окно любого размера).

## Что нужно от вас (я не могу сделать это сам)
1. Export templates Godot 4.7.2 и симулятор iOS — **уже установлены на этой машине**.
3. **Подпись**: Apple ID / Team ID и Bundle ID. Для запуска на своём iPhone достаточно бесплатного Apple ID (Personal Team); для TestFlight/App Store нужна платная учётная запись. Ключи и профили в репозиторий не кладутся.

## Сборка
```bash
cp platform/ios/export_presets.cfg.template export_presets.cfg   # заполните FILL_IN
godot --headless --path . --export-release "iOS" build/ios/IronDominion.ipa
```
Режим `export_project_only=true` создаёт Xcode-проект: откройте его в Xcode, выберите устройство или симулятор и запустите.

## Что ещё предстоит (честный список)
- Первый запуск на реальном устройстве и измерение кадров/памяти (цель: HD-карта ≥ 30 FPS на iPhone 12 и новее). В симуляторе процесс занимает ≈ 100 % одного ядра даже в меню. Что именно перерисовывается каждый кадр, найти не удалось; сделано: анимированные параметры шейдера обновляются только при изменении, на телефоне 30 FPS в покое и 60 при касании, фоновый дрейф меню отключён. Симулятор эмулирует графику на CPU Mac, поэтому цифра не показатель — на устройстве смотрите Instruments (Energy/Time Profiler).
- Портретная раскладка: HUD рассчитан на ландшафт.
- Экранная клавиатура для поиска и проверка всех панелей под палец.
- Реализовано: на телефонах качество карты «среднее» (тайлы только при приближении), кнопки с увеличенными полями под палец. Не измерено на устройстве.


## Запуск на своём iPhone по кабелю (бесплатный Apple ID, без подписки)
Нужны: iPhone, кабель, Xcode (есть), Apple ID. Платная программа не нужна — приложение будет жить 7 дней, потом его надо снова поставить из Xcode.
1. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится).
2. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять этому компьютеру».
3. Экспорт проекта для устройства (шаблоны уже установлены; для устройства нужна обычная arm64-библиотека из шаблонов):
```bash
mkdir -p build/ios-device && godot --headless --path . --export-debug "iOS" build/ios-device/IronDominion.xcodeproj
open build/ios-device/IronDominion.xcodeproj
```
4. В Xcode: цель **IronDominion** → Signing & Capabilities → «Automatically manage signing» → **Team**: ваш Personal Team (Xcode → Settings → Accounts → добавить Apple ID).
5. Там же замените **Bundle Identifier** на уникальный (например `com.<ваше-имя>.irondominion`): `com.example.irondominion` занят/не принимается Apple.
6. Вверху выберите ваш iPhone как устройство → ▶ Run. При первом запуске: Настройки iPhone → Основные → VPN и управление устройством → доверять профилю разработчика.
7. Если Xcode ругается на `libgodot` для устройства — это шаблоны: проверьте, что в проекте есть `IronDominion.xcframework/ios-arm64/libgodot.a` (там arm64, он рабочий).

Файл с данными (`IronDominion.pck`, ≈ 56 МБ без XL-карты) копируется в приложение автоматически. Для iPhone в сборку не входит XL-карта.
