IRON DOMINION — Windows (x64)
=============================

Глобальная стратегия на реальной карте мира. Одиночная игра, установка не нужна:
распакуйте архив в любую папку (в том числе с кириллицей и пробелами) и запустите IronDominion.exe.
All data is inside the EXE. No installer, no administrator rights.

Требования
----------
* Windows 10 / 11, 64-бит (x64).
* Видеокарта с поддержкой Vulkan 1.0 (драйвер NVIDIA / AMD / Intel 2020 года или новее). Без Vulkan игра не запустится.
* 4 ГБ ОЗУ (игра занимает около 0.8 ГБ), ~200 МБ на диске.

Быстрый старт
-------------
1. Запустите IronDominion.exe.
2. «Сценарии» → «Современный мир» → выберите государство.
3. Пробел — пауза, 1–4 — скорость, колесо мыши — масштаб, перетаскивание — камера.

Управление
----------
ЛКМ — выбор клетки / цель приказа · ПКМ — контекстное меню (война, союз, мир, аннексия занятого, центрирование)
Колесо / перетаскивание — масштаб / камера · Пробел — пауза · 1–4 — скорость · M — режим карты
Ctrl+F или / — поиск города и региона · F5 — быстрое сохранение · F9 — загрузить сохранение
F11 — полный экран · Esc — снять выбор · ☰ (меню) — сохранить/загрузить/масштаб интерфейса/качество графики
Горячие клавиши работают на любой раскладке (в том числе русской): учитывается положение клавиши.

Окно и графика
--------------
F11 или меню ☰: полный экран, окно без рамки, размер окна (1366×768 … 3840×2160).
Меню ☰ → «Качество графики»: Низкое / Среднее / Высокое (если игра тормозит — выберите «Низкое»).
Масштаб интерфейса: меню ☰ → «Масштаб интерфейса +/−».

Где лежат данные
----------------
Сохранения, настройки и моды: %APPDATA%\Godot\app_userdata\Iron Dominion\
  saves\     — сохранения (quick.sav — F5, auto.sav — автосохранение)
  display.cfg, graphics.cfg — настройки окна и качества
  scenarios\ — пользовательские сценарии, mods\data\ — моды данных
Удалить игру = удалить папку с EXE (и, по желанию, папку выше).

Если что-то не так
------------------
* Окно не открывается / сразу закрывается: обновите драйвер видеокарты (нужен Vulkan).
* Windows SmartScreen: сборка не подписана сертификатом издателя — «Подробнее» → «Выполнить в любом случае».
* Низкий FPS: меню ☰ → «Качество графики» → «Низкое». На скорости ×20 симуляция тяжёлая — используйте ×8.
* Сообщите о проблеме: https://github.com/KIR223/game-universal/issues (приложите VERSION.txt).
