- Сетевого мультиплеера, звука, собственного шрифта, исторических сценариев (см. `ROADMAP.md`), мирных переговоров с частичными уступками.

- Редактора сценариев для реального мира.

## 6. Что требует адаптации / особенностей Windows
- Окно ОС ограничивает размер окна рабочей областью экрана (4K на FullHD-мониторе → окно 1924×1061): режимы разрешений ограничиваются экраном.
- Безрамочное окно размером ровно с экран Windows превращает в эксклюзивный полноэкранный режим → окно на 1 px выше экрана (PR #14).
- Раскладка клавиатуры: горячие клавиши завязаны на физическое положение клавиши (PR #22).
- Пути данных: `%APPDATA%\Godot\app_userdata\Iron Dominion\` (сохранения, настройки, моды); кириллица и пробелы проверены.
- `winget` без прав администратора не создаёт алиас `godot`; Python из Microsoft Store — заглушка (нужен `winget install Python.Python.3.12`).

## 7. Файлы и контракты, которые нельзя менять без согласования с macOS-разработчиком
- `data/world/*` (формат, ID ячеек, `world_hash`) и `tools/world/build_world.py` (меняет хеш).
- Публичный API симуляции: `apply_command()` (набор команд и поля), `tick_day()`, `checksum()` (PR #20 изменил состав — **значения изменятся**), структура `Simulation.to_dict()`, `SAVE_VERSION`.
- `project.godot`: версия движка, рендерер; общие настройки (PR #16 добавляет `import_etc2_astc` и переопределение рендерера только для Android).
- Общие файлы, которые затронуты моими PR и требуют ревью: `main.gd`, `map_view.gd`, `earth_map_view.gd`, `simulation.gd`, `run_tests.gd`, `run_ui_tests.gd`, `ci.yml`.

## 8. Ошибки и предупреждения на Windows
- Падений и ошибок тестов нет. Предупреждения о утечке RID/ObjectDB при выходе UI-тестов (headless, dummy renderer) — безвредны.
- Git сообщает «CRLF will be replaced by LF» (рабочая копия Windows) — безвредно, в репозитории LF.
- `adb` иногда теряет эмулятор после перезапуска демона («device offline») — `adb kill-server` и повтор.
