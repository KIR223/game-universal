# Architecture

**Правило №1: симуляция отделена от графики.** Всё в `game/simulation`, `game/world`, `game/core` — чистые данные без Node;
работает headless, одинаково на всех платформах. `game/rendering` и `game/ui` только читают состояние.

| Слой | Папка | Файлы сейчас |
|------|-------|--------------|
| Генерация мира | `game/world` | `world_gen.gd` — детерминированная карта по seed, провинции, соседи |
| Симуляция | `game/simulation` | `simulation.gd` — время, экономика, армии, бои, оккупация, ИИ, команды, чексумма |
| Сохранения | `game/core` | `save_system.gd` — save/load через `Simulation.to_dict/from_dict` |
| Рендер | `game/rendering` | `map_view.gd` — рельеф, границы, армии, подписи, камера |
| UI | `game/ui` | `main.gd` — меню, выбор страны, HUD |
| Данные | `data/`, `shared/` | `countries.json` (версионированы, `schema_version`) |

## Реальная карта (world overhaul)

- `data/world/` + `game/world/earth_world.gd`: неизменяемый набор данных (ячейки, регионы, страны, поселения, дороги); общий для всех платформ, версионирован `world_hash`.
- Территориальная модель: `WORLD → COUNTRY → REGION → (DISTRICT) → SETTLEMENT → CELL`. Ячейка — единица военной симуляции («провинция» для всех систем), вложена в регион, но контроль над ней независим от административных границ.
- `Simulation.owner[]` — **игровой контроль** ячейки, `Simulation.legal[]` — признанная принадлежность; оккупация меняет только `owner[]`.
- `game/rendering/earth_map_view.gd` + `earth_map.gdshader`: шейдер по палитре на ячейку, векторные слои (чанки + меши), LOD, режимы карты.
- Старая процедурная карта (`world_gen.gd`, `MapView`) сохранена для сценариев `"world": "procedural"` и сохранений v10.

## Контракты (не ломать без согласования с Windows-разработчиком)

- Игрок/сеть меняют состояние **только** через `Simulation.apply_command(dict)`; команды валидируются и пишутся в `command_log`.
- Время идёт только через `tick_day()`; случайность — только `Simulation.rng` (seed); целые числа для экономики.
- `Simulation.checksum()` — отпечаток состояния для обнаружения рассинхронизации в мультиплеере.
- Сохранения версионированы (`SAVE_VERSION`, сейчас 11; `MIN_SAVE_VERSION` 10 мигрируется: `legal := owner`). Сохранение реального мира содержит `world_hash`; чужой набор данных не загружается молча.
- Всё состояние симуляции — целые числа (числа из JSON приводятся к int при загрузке).
- Один и тот же seed => один и тот же мир и ход игры (тесты `test_simulation_deterministic`, `test_save_roundtrip`).
- Движок: Godot 4.7.2, рендерер `mobile` (Metal/Vulkan). Смена движка/рендерера — только по согласованию.
