# Итоговая проверка iPhone-версии

Дата: 2026-11-17/18 · коммит ветки `feature/ultimate-game-expansion` · Xcode 27.2, iOS 27.2, симулятор **iPhone 17** (экран 874×402 pt, scale 3) · Godot 4.7.2.
**Физический iPhone недоступен — проверка на устройстве НЕ выполнена.** Всё ниже проверено в симуляторе iOS и сборкой под устройство без подписи. Успешный экспорт не выдаётся за работоспособность на телефоне.

## Важные оговорки
1. **Симулятор рисует через OpenGL ES на процессоре Mac** (в журнале: «Setting up an OpenGL ES 3.0 context»; библиотека симулятора собрана без Metal). Кадр занимает ≈ 1,5 с. Числа скорости и времён загрузки из симулятора **не отражают** реальный iPhone и приведены только как справка.
2. Официальные шаблоны Godot 4.7.2 содержат библиотеку симулятора только для x86_64 (iOS 27 такое не запускает). arm64-библиотека для симулятора собрана из исходников Godot 4.7.2 (`scons platform=ios arch=arm64 ios_simulator=yes target=template_debug vulkan=no`, 7–15 мин; кэш `~/Library/Caches/irondominion_godot`). Сборка: `platform/ios/build_simulator.sh`.
3. Консольный вывод игры в симуляторе не перехватывался; результаты автопроверки читаются из файла `Documents/qa_report.json` приложения (`--qa-run`, код `game/core/qa_runner.gd`, 32 проверки).

## Что нужно, чтобы закрыть NOT TESTED
1. Запустить на своём iPhone по инструкции (`platform/ios/README.md`, Personal Team, свой bundle ID).
2. Снять Instruments: Time Profiler, Allocations, Energy Log, Metal System Trace; замерить FPS/память/загрузку (`--qa-run` на устройстве пишет те же метрики в `Documents/qa_report.json`, их можно скопировать через Files или Xcode → Devices).
3. Проверить рендер Metal (в симуляторе он не используется).

## Найдено и исправлено в ходе проверки
- Верхняя панель шире экрана на телефоне → 5 главных показателей, остальные ресурсы в «Экономике».
- Кнопки ≈ 29 pt → 44 pt (расчёт от масштаба экрана, тест).
- Панели налезали на нижнюю навигацию и под верхнюю панель → единая высота и верхний край (`PANEL_Y`, `_panel_h` по размеру области без отступов).
- «Invalid polygon» при сильном приближении (треугольники аэродромов и ромбы столиц схлопывались).
- Скрипт сборки учитывает `DEVELOPER_DIR` (после перезапуска macOS `xcode-select` указывал на Command Line Tools).
