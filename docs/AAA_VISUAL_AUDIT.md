# Визуальный аудит IRON DOMINION

Дата: 2026-11-17. Версия: `main` + PR #32 (iOS) + ветка `feature/aaa-visual-overhaul`. Сняты скриншоты 10 экранов на HD-карте (macOS, 1600×900):
меню, выбор страны, политическая карта, рельеф, военный режим, максимальное приближение, технологии, дипломатия, политика, армия.
Скриншоты не хранятся в репозитории (пересоздаются скриптом из этого аудита); эталонные скриншоты — в плане (см. «Не сделано»).

## Что хорошо (проверено)
- Геометрия: Web Mercator, точный берег Natural Earth 10m, тайлы NE2, реки/озёра/границы тонкими линиями.
- Подписи: страны без наложений, области по масштабу, названия на русском там, где они есть в данных.
- Главное меню и экран сценариев: единый стиль (золото + графит), карта в фоне.
- Скорость: HD/XL 57–143 FPS на M1 при перемещении и масштабировании (`docs/BENCHMARKS.md`).

## Проблемы (приоритеты)
### P0 — ломают игру визуально
| № | Проблема | Статус |
|---|---|---|
| P0-1 | Панели (экономика, технологии, дипломатия) растягивались на всю ширину и закрывали верхнюю панель и левую рейку | **исправлено** (регрессия безопасных зон, проверка в `run_ui_tests.gd`) |
| P0-2 | На рабочем столе весь интерфейс был сдвинут вниз на ~60 px (безопасная зона ОС принималась за вырез экрана) | **исправлено**: безопасные зоны только на телефонах |
| P0-3 | Нижняя карточка территории обрезает текст («Добыча…», кнопки) | **частично**: карточка выше (232 px на ПК, 156 на телефоне), текст прокручивается; перекомпоновка в колонки — открыто |
### P1 — заметно портят впечатление
| № | Проблема | Статус |
|---|---|---|
| P1-1 | Пункты на среднем масштабе — белые квадраты, слипаются в «кляксы» | **улучшено**: три размера точек по населению, порог плотности по масштабу |
| P1-2 | Подписи городов местами перекрывают подписи областей и стран | открыто (стран уже без наложений) |
| P1-3 | Модальные панели — серые «простыни» без иерархии, без иконок, разные кнопки по высоте | открыто |
| P1-4 | Правая панель «События» в начале пустая, занимает ~25 % экрана | частично (приветствие) |
| P1-5 | В режиме «Рельеф» политический цвет по-прежнему сильно перекрывает рельеф на дальнем плане | открыто |
| P1-6 | Нет затухающих анимаций открытия панелей у всех панелей (есть у части) | открыто |
### P2 — полировка
| № | Проблема | Статус |
|---|---|---|
| P2-1 | Единый набор иконок только у левой рейки; остальное — текст | открыто |
| P2-2 | Нет звука, нет настроек громкости и «уменьшения движения» | **сделано**: процедурные звуки интерфейса и фоновая музыка (оригинальные, без лицензий), громкости и «уменьшить движение» в настройках |
| P2-3 | Нет профилей качества Low/Medium/High/Ultra в настройках игрока | **сделано**: профили меняют тайлы карты, число подписей, анимацию воды; сохраняются в `user://settings.cfg` |
| P2-4 | Нет отдельной мобильной раскладки (портрет, нижняя навигация, выдвижные панели) | открыто |
| P2-5 | Вода без анимации, нет погодных эффектов на карте | **частично**: мягкая анимация воды (шейдер, выключается профилем «Низкое» и «уменьшить движение»); дождь/снег/туман — открыто |
| P2-6 | 3D/2.5D рельеф с освещением и тенями не реализован | открыто |

## Не сделано в этом аудите
Физическая карта с отдельным материалом биомов, автоматическое сравнение с эталонными скриншотами, аудит разных разрешений и локализаций.

## Что проверяется автоматически сейчас
- `tests/run_ui_tests.gd`: верхняя панель у края окна, ширина и положение модальных панелей, отсутствие перекрытия верхней панели и рейки.
- `tests/run_tests.gd`: токены дизайна (сетка 4 px, контраст текста ≥ 4,5:1), жесты и безопасные зоны.
