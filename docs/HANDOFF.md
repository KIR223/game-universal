# Handoff (последнее обновление: 2026-11-16)

**Состояние:** играбельный вертикальный срез. Меню → выбор государства → карта мира, ход времени, армии (выбрать → клик по цели),
найм, война, ИИ других стран, сохранение (F5). 1839 проверок + 47 UI-проверок проходит headless.

**Окружение (macOS M1, 8 ГБ):** Godot в `~/Applications/Godot.app`, симлинк `~/.local/bin/godot`, `gh` в `~/.local/bin`
(добавьте `~/.local/bin` в PATH). Homebrew не установлен (нужен sudo).

**Известные ограничения:**  на разных материках не могут воевать (нет флота); нет мира кроме белого по таймеру и капитуляции;
баланс сырой (AI копит деньги — тратить нечем; игрок без действий быстро теряет страну после дня 60); macOS-экспорт не настроен (нужны export templates + `export_presets.cfg`).

**Баланс снабжения:** армии глубоко во вражеской земле падают до ~10% снабжения (−1% силы/день), ИИ этого не учитывает — стоит добавить отход/подвоз.

**Реальная карта (ветка `feature/world-overhaul`):** сценарий «Современный мир» (205 стран, 14 779 ячеек). Данные: `data/world` (пересборка — `tools/world/build_world.py`, ≈ 70 с). Известные ограничения: районы только как название у населённых пунктов; нет исторических слоёв; армии/казна/идеологии стран — оценки; мирные договоры пока не меняют `legal[]`; симуляция ≈ 50 мс/день (до ~8 дней/с); редактор сценариев не поддерживает реальный мир (используйте моды данных и JSON).

**Следующие шаги:** 1) Дивизии, генералы, снабжение. 3) Авиация. 4) Технологии. 5) Политика и события. 6) macOS export + CI-сборка.
